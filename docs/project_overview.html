🌱 AgriVox

Smart Agriculture Voice Platform

AgriVox is an AI-powered voice platform that brings smart agriculture capabilities to every farmer. This document explains the system architecture and data flow.

📊 Data Flow

1
Voice Input: User speaks naturally in any of 12+ Indian languages
2
Processing: Server action calls processVoiceAction with AI processing
3
AI Engine: Google Gemini 3.0 Flash extracts structured data using schema validation
4
Validation: Output mapped to Beckn Protocol schema with Zod validation
5
Storage: Catalog stored in database via Prisma ORM
6
Broadcast: ONDC network simulation with real-time buyer matching

🛠️ Technology Stack

Framework:
Next.js 15 + React 19
Styling:
Tailwind CSS 4
Database:
PostgreSQL / SQLite
AI Engine:
Google Gemini 3.0 Flash
Protocol:
ONDC Beckn v1.2.0
Infrastructure:
Docker + GCP

🤖 Why Gemini 3.0 Flash?

Current Implementation: Uses google('gemini-3-flash-preview') via Vercel AI SDK
  1. Speed: Flash model provides sub-second response times for voice interactions
  2. Multilingual: Native support for 12+ Indian languages including dialect handling
  3. Structured Output: JSON mode ensures Beckn Protocol compliance
  4. Cost Effective: Optimized for high-volume, low-latency use cases
