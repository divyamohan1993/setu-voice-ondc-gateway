### Software Stack Used

**Frontend Framework & UI:**
*   **Next.js 15 (App Router):** React framework with server components and App Router architecture
*   **React 19:** Modern React with concurrent features
*   **Tailwind CSS 4:** Utility-first CSS framework with custom design system
*   **Framer Motion:** Production-ready motion library for React animations
*   **Lucide React:** Consistent, modern icon set
*   **Radix UI:** Accessible, headless UI primitives

**Backend & Database:**
*   **Node.js 20+:** JavaScript runtime environment
*   **Prisma 7:** Next-generation ORM for type-safe database access
*   **PostgreSQL 16:** Production-grade relational database
*   **SQLite:** Lightweight development database
*   **Zod:** TypeScript-first schema validation

**AI & Machine Learning:**
*   **Google Gemini 3.0 Flash:** State-of-art LLM for multilingual voice understanding and entity extraction
*   **Vercel AI SDK:** Unified API for AI model integration with streaming support
*   **Web Speech API:** Browser-native speech recognition and synthesis

**Protocols & Standards:**
*   **ONDC Beckn Protocol (v1.2.0):** Government-mandated open commerce standard
*   **Agmarknet API:** Real-time government Mandi price data

**DevOps & Infrastructure:**
*   **Docker & Docker Compose:** Container orchestration for consistent deployments
*   **Google Cloud Platform (GCP):** Cloud Run for serverless deployment, Cloud SQL for managed PostgreSQL
*   **GitHub Actions:** CI/CD pipeline for automated testing and deployment
*   **Vitest:** Modern, Vite-native testing framework

**IoT-Ready Architecture:**
*   **WebSocket Support:** Real-time bidirectional communication
*   **REST API:** Standard HTTP endpoints for sensor integration
*   **MQTT Ready:** Architecture designed for future IoT device integration
