# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-02-05

### Added
- Complete redesign with new dark theme and modern UI
- AgriVoxInterface component with glassmorphism design
- Smart agriculture focus with IoT-ready architecture
- New emerald/blue color palette
- Enhanced voice visualizations and animations

### Changed
- Rebranded to AgriVox Smart Agriculture Platform
- Upgraded design system with new CSS variables
- Improved accessibility and WCAG compliance
- Modernized component structure

## [1.0.0] - 2026-01-27

### Added
- Initial release with voice commerce capabilities
- Core Voice Interface component
- Visual Verifier component
- Network Simulator
- Docker and Docker Compose setup
- Integration with Vercel AI SDK and Google Gemini
- Local SQLite and Production PostgreSQL support
